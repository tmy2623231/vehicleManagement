Program.cs 是唯一的进程入口：通过 WebApplication.CreateBuilder 注册 Serilog、Razor Pages、ServerSideBlazor、HttpContextAccessor；使用 IDbContextFactory<VehicleDbContext> 与 IDbContextFactory<AiServerDbContext> 分别连接两个 SQLite 数据库（DefaultConnection / AiServerConnection），避免 Blazor Server 并发下的 DbContext 共享问题。启动时创建 data/ 与 Folder/ 目录，调用 EnsureCreatedAsync 初始化两张表并在 Development 环境执行 SeedDataInitializer。业务仓储（VehicleRepository、DepartmentRepository 等）与 BLL 服务（VehicleService、ChatService 等）以及 SemanticKernel 实例均在此集中 AddScoped/ AddSingleton 注册，_Imports.razor 将 vehicleManagement.* 与 vehicleManagement.aiServer.* 命名空间暴露给所有 .razor 页面，从而把车辆管理业务层、AI 对话子系统与静态资源串联为一个单 Blazor Server 应用。
