- Service 类通过构造函数注入 Repository、IDbContextFactory<VehicleDbContext>、ILogger<T> 等依赖，避免直接 new DbContext。
- 需要临时数据库连接的方法使用 await using var db = await _dbFactory.CreateDbContextAsync() 获取上下文，确保自动释放。
- 分页查询统一返回 BLL.Common.PagedResult<T>，并在 Service 内处理页码边界修正与 Count + Skip/Take 的延迟求值。
- 时间字段统一使用 DAL.Common.ChinaTime.Now 赋值，而非直接使用 DateTime.Now。
- 涉及文件删除或外部资源的操作包裹 try/catch 并通过 ILogger 记录日志，失败时返回 (bool, string) 元组向调用方传递错误信息。
- Blazor 页面通过 @inject 注入 Service，并在 OnInitializedAsync 中加载数据、OnAfterRenderAsync 中执行 JS Interop 渲染图表。
