目录按浏览器资源类型划分：`css/` 存放站点级样式（`site.css` 覆盖 Blazor NavLink、表单控件、图表卡片，`design-system.css` 定义设计系统变量，`ai-chat.css` 专用于 AI 聊天界面）；`js/` 中 `charts.js` 基于 Chart.js UMD 包封装 `window.charts` API（环形图、柱状图、折线图），统一使用 Cyan 主题色板与 Geist 字体，并通过 `_instances` 字典管理实例生命周期；`layout-diagnostics.js` 暴露 `window.checkLayoutFill()` 工具函数，检测 `.aim-root/.main-content/.aim-main/.aim-side` 等容器的填充空白并可选绘制红色标记框；`fonts/` 内嵌 Geist 字重变体供 CSS 引用；`uploads/images|videos` 为运行时用户上传的媒体目录；根级 `favicon.ico` 提供站点图标。依赖方向单向：JS 仅消费 DOM 与 Chart.js，CSS 通过 CSS 变量耦合设计系统，无模块间 JS 依赖。
