模块按三层划分：
- Pages/AiChat.razor：Blazor 页面层，通过 `@inject ChatService` 消费业务接口，负责 UI 状态（会话列表、消息流、记忆面板）、移动端侧边栏、滚动监听及 F12 布局诊断。
- BLL/：业务编排层，`ChatService` 是入口，串联 `IntentDetector`（静态方法，基于 `Enums/UserIntent.cs` 分类）、`DataQuerier`（SQL 查询注入）、`MemoryService`（异步提取记忆）与 `Kernel/IChatCompletionService`（Semantic Kernel），并通过 `Prompts/SystemPrompts.cs` 注入系统提示词；依赖方向单向指向 DAL。
- DAL/：数据访问层，使用 EF Core 的独立 `AiServerDbContext`，定义 `ChatSession`/`ChatMessage`/`ChatMemory` 三个实体及其关系（级联删除、SetNull），并通过 Repository 子目录中的 `*Repository.cs` 封装 CRUD 操作。

依赖方向严格为 Pages → BLL → DAL，BLL 不感知 Razor 页面，DAL 不感知上层框架。
