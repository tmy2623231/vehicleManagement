模块按 BLL / DAL / Pages / Components 四层组织，依赖方向单向自上而下：
- BLL（业务逻辑层）：每个领域实体对应一个 Service 类（VehicleService、DepartmentService、PersonnelService、LocationService、MaintenanceRecordService、UsageRecordService、DashboardService、ExecuteService），通过构造函数注入 Repository、IDbContextFactory<VehicleDbContext>、FileUploadService、QrCodeService、ICurrentUser、AuditService 等协作对象；跨实体的校验与事务性操作（如删除车辆前清理附件、生成二维码 Token、权限隔离）集中在 Service 中完成。
- DAL（数据访问层）：VehicleDbContext 集中声明 DbSet 与 EF Core 模型配置（HasIndex/HasOne/OnDelete），Repository 子目录提供通用仓储接口及具体实现，Model 子目录存放 POCO 实体与 VehicleEnums，ChinaTime 封装统一时区，SeedDataInitializer 负责初始数据，SchemaBootstrapper 幂等建立账号与审计表。
- Pages：Blazor Server 页面（Vehicles、Departments、Locations、PersonnelList、UsageRecords、MaintenanceRecords、BorrowForm、MaintenanceForm、Execute、Index）通过 @inject 注入对应 Service，调用异步方法并渲染表格、图表与表单。
- Components：可复用 UI 组件按职责分目录——Common/Pagination.razor、Layouts/MainLayout & MobileLayout、Navigation/NavMenu、Tables/Forms（空目录预留）。MainLayout 组合 NavMenu 与顶部栏，@Body 承载页面内容。
- 共享工具：BLL/Common 下的 FileUploadService、PagedResult<T>、QrCodeService 被多个 Service 复用。
