模块按三层划分，依赖方向严格为 Pages → BLL → DAL：
- Pages/AiChat.razor：Blazor Server 页面层，通过 `@inject ChatService` 消费业务接口，负责 UI 状态（会话列表、消息流、记忆面板）、移动端侧边栏、滚动监听及 F12 布局诊断。
- BLL/：业务编排层，`ChatService` 是入口，串联 `IntentDetector`（静态方法，基于 `Enums/UserIntent.cs` 分类）、`DataQuerier`（调用上层 Vehicle/Department/Personnel/UsageRecord/Dashboard Service 将数据格式化为 LLM 可读文本）、`MemoryService`（异步提取记忆）与 `Kernel/IChatCompletionService`（Semantic Kernel），并通过 `Prompts/SystemPrompts.cs` 注入系统提示词；另含 `TextToSqlService` 作为可开关的副路径，在规则未命中时让模型生成白名单 SQL 并只读执行。
- DAL/：数据访问层，使用独立 `AiServerDbContext`（EF Core），定义 `ChatSession`/`ChatMessage`/`ChatMemory` 三个实体及其关系（级联删除、SetNull），并通过 Repository 子目录中的 `*Repository.cs` 封装 CRUD 操作。
- 配置与边界：`AiServerOptions` 集中承载超时、Temperature、MaxTokens、TextToSqlEnabled 等开关；`UnavailableChatCompletionService` 作为兜底实现；`ChatCompletionPathHandler` 暴露 HTTP 端点供外部调用。
