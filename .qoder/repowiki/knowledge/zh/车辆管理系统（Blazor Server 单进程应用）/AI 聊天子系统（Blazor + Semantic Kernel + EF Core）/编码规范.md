- BLL 中的服务类通过构造函数注入 Repository、Kernel、ILogger 等依赖，避免在类内部直接 new 对象。
- DAL 中每个 Model 对应一个同名的 Repository 文件，CRUD 操作以 async Task<T>/Task<IEnumerable<T>> 形式暴露。
- System prompts 集中放在 Prompts/SystemPrompts.cs，通过常量或静态方法（如 BuildDataInjectionPrompt）构造 ChatHistory 的系统消息。
- UI 交互通过 JSInvokable 与 IJSRuntime 桥接浏览器能力（滚动监听、布局诊断），C# 端仅持有 DotNetObjectReference。
- 非关键路径的副作用（如记忆提取）采用 try/catch 吞掉异常并记录日志，不影响主对话流程。
- 面向用户的错误文案不携带异常细节（主机名、端口、内部路径），统一转为友好提示并由 ILogger 记录原始异常。
