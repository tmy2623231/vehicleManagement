Program.cs 是唯一的进程入口：通过 WebApplication.CreateBuilder 注册 Serilog、Razor Pages、ServerSideBlazor、HttpContextAccessor，并集中 AddScoped/ AddSingleton 注册 vehicle_management_app 的仓储与服务、ai_chat_subsystem 的 SemanticKernel 实例以及 QrCodeService 等全局组件；_Imports.razor 暴露 vehicleManagement.* 与 vehicleManagement.aiServer.* 命名空间，使三个子模块在 .razor 页面中直接互通。
- 数据层：使用 IDbContextFactory<VehicleDbContext>（DefaultConnection）与 IDbContextFactory<AiServerDbContext>（AiServerConnection）分别连接两个 SQLite 文件，避免 Blazor Server 并发下的 DbContext 共享问题；启动时 EnsureCreatedAsync 建表并在 Development 环境执行 SeedDataInitializer。
- 存储：data/ 目录存放 VehicleDbContext 数据，Folder/ 目录存放用户上传媒体；Dockerfile 挂载 aisettings.json 实现 AI 配置热重载。
- 边界：vehicle_management_app 负责领域模型与 EF Core 访问，ai_chat_subsystem 基于 Semantic Kernel + Ollama 提供意图驱动查询，static_assets 提供 CSS/JS/字体与上传目录，三者仅通过 DI 与 _Imports.razor 暴露的类型耦合。
