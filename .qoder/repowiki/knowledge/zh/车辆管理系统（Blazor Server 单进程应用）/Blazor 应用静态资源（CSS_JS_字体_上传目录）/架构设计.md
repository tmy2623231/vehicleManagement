按浏览器资源类型划分的扁平目录：`css/` 下 `design-system.css` 定义设计系统变量，`site.css` 覆盖 Blazor NavLink、表单控件与图表卡片，`ai-chat.css` 专用于 AI 聊天界面；`js/` 中 `chart.umd.min.js` 是 Chart.js UMD 构建产物，`charts.js` 在其之上暴露 `window.charts` API（环形图、柱状图、折线图），通过 `_instances` 字典以 canvas id 为键管理实例生命周期；`layout-diagnostics.js` 挂载 `window.checkLayoutFill()` 检测 `.aim-root/.main-content/.aim-main/.aim-side` 等容器的填充空白并可选绘制红色标记框；`fonts/` 内嵌 Geist Regular/Medium/SemiBold/Bold TTF 供 CSS 引用；`uploads/images|videos` 为运行时写入的媒体目录；根级 `favicon.ico` 提供站点图标。依赖方向单向：JS 仅消费 DOM 与 Chart.js，CSS 通过 CSS 变量耦合设计系统，模块间无 JS 依赖。
