- 图表实例通过 `window.charts` 命名空间对象暴露，并以 canvas id 为键在 `_instances` 中注册，销毁时调用 `destroyChart` 清理。
- 所有图表配色、字号、圆角等视觉参数集中在 `chartConfig.colors` 与 `chartConfig.fonts` 中，避免硬编码散落在各 chart 配置里。
- 图表创建前使用双重 `requestAnimationFrame` + `setTimeout` 延迟初始化，确保 Canvas 尺寸已计算完毕后再调用 `resize()`。
- 布局诊断类脚本通过挂载到 `window` 的全局函数对外暴露能力（如 `window.checkLayoutFill`），以选项对象控制行为（`draw`/`clear`）。
