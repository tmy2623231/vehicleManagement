- 跨子模块的服务与仓储统一在 Program.cs 中通过 ServiceCollection 注册，BLL 使用 AddScoped，全局单例（如 QrCodeService、Kernel）使用 AddSingleton
- 数据库访问一律通过 IDbContextFactory<T> 获取 DbContext，不直接注入 DbContext 以适配 Blazor Server 并发模型
- Blazor 页面通过 _Imports.razor 集中引入 vehicleManagement.* 与 vehicleManagement.aiServer.* 命名空间，避免在每个 .razor 文件中重复 using
